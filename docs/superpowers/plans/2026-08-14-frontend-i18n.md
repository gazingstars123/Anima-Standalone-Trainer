# Frontend Internationalization Implementation Plan

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans（内联执行）逐任务实现此计划。

**目标：** 为 `training-ui` 增加可持久化的中英文切换，并覆盖静态和动态用户界面文案。

**架构：** 使用无依赖的浏览器端 `i18n.js` 模块，维护 `en` 和 `zh-CN` 字典，向现有原生 JavaScript 应用提供 `t()` 和 `localechange` 事件。静态 DOM 使用文本映射和翻译属性，动态 HTML 使用现有状态通过 `tr()` 生成，不触碰后端配置值。

**技术栈：** 原生 HTML/CSS/JavaScript、Node `node:test`、localStorage。
